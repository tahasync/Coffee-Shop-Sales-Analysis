### 📈 Overview

This project analyzes **Coffee Shop beverage sales** comparing **March vs April** performance. The dataset covers hot coffees, iced drinks, and food items, revealing how staple products anchor revenue while seasonal offerings drive growth.

---

### 🔑 Key Insights

| Metric | Value |
|:-------|:------|
| **Total March Sales** | $25,050 |
| **Total April Sales** | $29,210 |
| **Overall Growth** | 16.6% |

#### Top 5 Products (April)
- **Latte** — $3,680 (12.6%)
- **Cappuccino** — $2,400 (8.2%)
- **Breakfast Sandwich** — $2,350 (8.0%)
- **Cold Brew** — $2,200 (7.5%)
- **Iced Latte** — $1,950 (6.7%)

#### Fastest Growing Products
- **Veggie Wrap** — 20.8% growth
- **Scone** — 20.0% growth
- **Coffee Beans** — 20.0% growth
